## 0.2.1 本輪進度

- 新增本機核定安裝入口：摘要預覽不寫入，核定同一摘要後先跑測試、示範及候選檔檢查，再保存設定／資料／收據與讀回。

### 驗證後清理（2026-10-06）

- 使用者核定後，已撤除本輪兩個隔離 Web App 的版本部署，兩個獨立試行 Apps Script 專案已移至垃圾桶，並由 Google API 讀回確認。未清空垃圾桶，未操作正式專案。
- 兩個試行程式的 Script Properties 均無資料綁定；以建立流程的固定名稱查詢，未找到測試 Sheet 或示範 PDF 資料夾。這是本輪清理查驗，不宣稱正式雲端儲存已驗收。
- 已停止本機示範服務，清除虛構業務資料、隔離部署產物、套件專用 npm 依賴及三個安裝測試暫存目錄；保留原始碼、GitHub、測試收據與示範 PDF 證據。未移除共用工具或帳號憑證。
- 本輪實際 LINE 發送仍為 0。GitHub 保留 54 個公開原始碼檔案；私人資源 ID、帳號、清理收據及截圖不納入公開來源。

下方 0.2.0 是歷史隔離部署紀錄，相關試部署已撤除，不能當作目前仍有可使用的雲端測試站或 0.2.1 已部署。後續試行須由單位另行核定，依 Google 隔離流程建立自己的新資源。

## 本機驗證

實際命令：`npm test`、`npm run demo`。測項數及完整結果需每次從程式重跑，不把本表當永久最新數字。

示範結果：兩台虛構設備、一筆日檢、一筆設備異常走到確認結案、一筆事件仍待處理；首次異常名單兩位虛構角色。`lineSent = 0`，`realPdfCreated = 0`。

測試確認同 ID 不重複寫、再次發現不重推、日／月不互抵、停用及跨場域排除、失格接手、中斷續作與已有副作用不作廢。未包含真實 Sheets 多寫者、手機 OAuth、Google 私有下載、真實 LINE 收件、投影機或正式營運成效。
