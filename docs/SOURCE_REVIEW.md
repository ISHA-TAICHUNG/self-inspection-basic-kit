## 已修正

- 中文 UTF-8 不逐封包解碼，合併後再解析 JSON。
- 本機暫存檔用唯一名稱及 exclusive 建立；釋放租約前比對 inode，不刪別人的檔案。
- Sheets 分段文字前綴防止公式解析，摘要及最新 seal 完整讀回。
- Web 只回傳本人的場域需求範本，不洩漏其他場域範本。
- Google 只取後端 active user 與核定名單，不信任 payload 身分，不以 effective user 代替。
- 案件視窗內顯示錯誤，並保留當頁同意圖網路重試。
- clasp 必須指定隔離目錄，不能意外推送上層正式專案。

## Gate

**僅允許隔離試行／明確標示的測試版原始碼分享。正式營運：BLOCKED。**

測試與掃描的實際次數以 IMPLEMENTATION_STATUS 為準。候選清單與 gitleaks 無命中不等於已無資安風險；部署建立不等於初始化、Google 多使用者、Drive 權限及通知送達已驗收。

正式門檻仍包括一般使用者與撤權、正式簽名／照片、背景恢復、部分副作用人工修復、備份還原、真實配額與效能及限定 LINE 實測。未提供 production sender，不能自行以解除 throw 的方式上線。
